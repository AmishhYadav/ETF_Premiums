# Paper, second draft, IEEE double-column version (12 Nov 2026)

Same text, tables, figures and numbers as the single-column version in `../draft2/`. Only the layout differs: IEEEtran journal class (two columns, 10 pt, A4), figures and wide tables spanning both columns, long equations broken over two lines, numeric citations [n] with the reference list in the natbib `plainnat` style.

Build: `sh build.sh` (pdflatex + bibtex; needs IEEEtran.cls, included here as the official v1.8b from CTAN). Analysis scripts are unchanged.
